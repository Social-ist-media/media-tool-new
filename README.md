# NEXUS

One feed. Twelve networks. A social command center.

## Repositories

- **Production monorepo:** [Mangu-Platforms/centuries](https://github.com/Mangu-Platforms/centuries) — Next.js web (`apps/web`) + Fastify API (`apps/api`)
- **This repo:** `redinc23/nexus-console` — GitHub home for the NEXUS console line

## Deploy

- Web → Vercel, root directory `apps/web` in the centuries monorepo
- API → Railway (see `DEPLOY.md` in centuries)

Demo workspace: chronological feed, composer, inbox, listening, studio, pipeline, grid, threads, copilot, care, crisis, and the rest of the command center.
